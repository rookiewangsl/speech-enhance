## 2. 单文件 RNNoise

输入必须是 16/48 kHz mono WAV：

```bash
./.venv/bin/python scripts/enhance_rnnoise.py \
  --input input.wav \
  --output output_rnnoise.wav \
  --mode official \
  --compensate-delay \
  --vad-json output_vad.json
```

`--compensate-delay` 只用于离线 A/B 和 paired metric。实时输出必须保留 10 ms（48 kHz）或
12.625 ms（16 kHz）因果延迟。`--chunk-size 137` 可压力测试非整帧输入；
`--pcm-compatible` 只用于与 official raw-PCM CLI 做量化等价检查。

录音链路为 48 kHz mono、480 samples/10 ms callback、persistent RNNoise state。系统没有

```text
dropped_blocks = 0
callback_status = []
processing_rtf < 1
output_clipping_samples = 0

```

真实麦克风没有同步 clean reference，不计算 SI-SDR/STOI；固定读稿可在人工 transcript 后
计算 WER，否则只做 raw/enhanced A/B、RTF、clipping 和主观检查。

### 4.1 实时增强 + 端点 ASR Demo

`realtime_asr_demo.py` 在同一条 48 kHz 麦克风流中持续运行 RNNoise；RNNoise VAD 检测到
一句话结束后，将增强输出流式降采样为 16 kHz，交给独立的 Whisper worker。ASR 推理不会阻塞
采集线程，因此不会因为一次较慢的转写而丢失后续麦克风帧。

这个脚本同时需要 ASR 和麦克风依赖；若使用独立的 `.venv-asr`，先补装 `demo` extra：

```bash
./.venv-asr/bin/pip install -e '.[asr,demo]'
```

```bash
./.venv-asr/bin/python scripts/realtime_asr_demo.py \
  --output-dir outputs/realtime_asr_demo \
  --duration 30
```

启动后终端会列出所有可用输入设备，输入对应编号即可。默认模型目录是
`/Volumes/T7/ProjectData/realtime_speech_enhancement/models/whisper`；需要脚本化运行或使用其他
目录时，才显式传入 `--device` 或 `--model-root`。增强后的 48 kHz 音频会同时实时播放到系统
默认输出设备；请使用耳机，因为该项目没有 AEC，使用扬声器会使播放音频回灌到麦克风。可用
`--output-device <编号或名称>` 选择耳机/声卡，或用 `--list-devices` 查询编号。
实时 Demo 默认使用 CPU ASR，以避免 MPS 解码产生不稳定文本；若只想做速度实验，可显式传入
`--asr-device mps`。

终端会在每次端点完成后显示最终转写。`outputs/realtime_asr_demo/` 同时保留
`microphone_raw.wav`、`microphone_rnnoise.wav`、`transcripts.jsonl`、`transcripts_timeline.png` 和
`report.json`。`transcripts_timeline.png` 以时间轴标出每段语音的开始/结束时刻和转写文本。对历史
JSONL 可单独生成 PNG：

```bash
./.venv-asr/bin/python scripts/plot_asr_timeline.py \
  --input outputs/realtime_asr_demo/transcripts.jsonl
```

旧 JSONL 未记录绝对起始时刻，不能按段长从 0 秒推算。若同目录有对应的 `microphone_raw.wav` 和
`report.json`，绘图器会重放 RNNoise/VAD 来恢复真实端点；缺少这两个文件时会拒绝生成带伪时间的图。
新运行会直接写入真实段时刻。
默认配置
使用 `small.en`，只用于英文；中文演示必须提供 16 kHz 多语言 Whisper 配置（例如模型名为
`small` 且 `decoding.language` 为 `zh`）。该脚本是**端点式 ASR**：静音约 700 ms 后输出一句
最终文本；传话过程中不断刷新局部文本需要另行实现滑动窗口或原生流式 ASR。

## 10. 常见问题

- 找不到 RNNoise 共享库：运行 `./scripts/setup_rnnoise.sh`。
- 找不到麦克风依赖：运行 `./.venv/bin/pip install -e '.[demo]'`。
- 输出比输入晚：这是因果延迟，不是文件损坏。
- SI-SDR 极低：先检查是否补偿完整 202 samples，而不是只补 FIR 延迟。
- ASR 缓存未命中：检查音频、模型、配置、evaluator 和 runtime identity SHA。
- MPS 更快但文本不同：正式结果继续使用 CPU，速度不能覆盖身份不一致。
- DNSMOS 模型缺失或 SHA 不符：重新运行 `scripts/download_dnsmos.py`，不要把 ONNX 权重提交
  到 Git。

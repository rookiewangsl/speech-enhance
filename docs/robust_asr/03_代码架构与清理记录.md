# 代码架构与清理记录

更新日期：2026-08-28

## 1. 清理目标

本仓库现在只服务于“普通话远场混响鲁棒 ASR”这一条主线。历史实时语音增强项目已经完成
它的阶段性验证，但其 RNNoise、MCRA、VAD、VoiceBank+DEMAND 和英文 Whisper 代码与当前实验
没有运行依赖。继续混放会模糊项目定位，也会让测试、依赖和命令入口难以维护，因此从活动代码树移除。

本次清理没有删除外部数据盘或服务器上的原始数据、模型权重和实验缓存。Git 内被删除的历史代码
仍可从清理前提交 `767413b6df696f2b99aa5e5b1d52769834520b9e` 恢复。

## 2. 项目数据流

```text
AISHELL-1 manifest
        │
        ▼
   干净单通道语音 ──► RIR 选择与卷积 ──► 混响多通道语音
                                             │
                         ┌───────────────────┼────────────────────┐
                         ▼                   ▼                    ▼
                       Raw             单通道 WPE             多通道 WPE
                         └───────────────────┼────────────────────┘
                                             ▼
                                  冻结或 LoRA Whisper
                                             ▼
                               中文归一化、CER、S/D/I
                                             ▼
                         RT60 分层结果、DRR 解释与配对统计
```

后续多条件训练会从同一训练 manifest 按冻结比例采样 clean/raw-reverberant 输入。前端消融与模型
适配共享数据划分和评分协议，避免因样本或解码设置不同而产生不可比结果。

## 3. 分层与职责

| 层级 | 位置 | 职责 |
|---|---|---|
| 冻结协议 | `configs/robust_asr/` | 数据规模、RT60 档位、几何、前端参数、模型 revision、随机种子 |
| 核心库 | `src/robust_asr/` | 可测试的领域逻辑，不处理命令行交互 |
| 命令入口 | `scripts/robust_asr/` | 解析参数并调用核心库，不重复实现算法 |
| 自动验证 | `tests/` | 协议、数据处理、声学仿真、WPE、模型接口和评分测试 |
| 实验文档 | `docs/robust_asr/` | 计划、执行证据、结论边界和面试叙事 |
| 外部状态 | Git 之外 | AISHELL、RIR、模型、检查点和可重建输出 |

## 5. 已移除内容

- 历史 `speech_frontend` 包及其 RNNoise、MCRA、Wiener、VAD、流式处理和英文 ASR 代码。
- VoiceBank+DEMAND、DNSMOS、RNNoise 和旧 Whisper 的配置、数据脚本、评测脚本及测试。
- 历史实验输出、文档图、RNNoise 许可证副本和旧项目手册。
- 已完成使命的一次性 Hugging Face 缓存修复脚本与合成 WPE smoke 命令。
- 没有生产调用方的 `CacheIdentity` 文件缓存抽象及其专属测试。
- 构建目录、Python 字节码、测试缓存和包元数据等生成物。

删除后的原则是：历史实验结果不再作为当前仓库的可运行功能；若需要审计，可查看 Git 历史，
不应把整个旧工程重新合并回当前主线。

## 6. 后续代码约束

1. 新功能只放在 `robust_asr` 命名空间，并对应冻结协议中的一个可解释实验变量。
2. 只有可复现的正式流程才新增命令入口；一次性排障优先写成测试或记录在执行文档中。
3. 数据、权重、检查点和生成结果不提交到 Git；正式结果只以小型表格和 PNG 图进入文档。
4. 修改协议或算法时同步更新测试、执行记录和结论边界。
5. 优化循环和正式训练完成前，不在文档或简历中把 LoRA 结果描述为已完成实验。

## 2. AISHELL-1 审计结果

数据根目录由参数或 `ROBUST_ASR_DATA_ROOT` 提供，代码中没有硬编码挂载路径。正式审计发现
141,925 个 WAV：其中 141,600 条有官方转写，325 条无官方转写（train 320、dev 5、test 0）。
无转写音频不会进入训练、模型选择或 CER 评测；其 ID 保留在 `audit.json`，因此不是静默删除。
不存在“有转写但无音频”的情况。

| 官方切分 | 可用条数 | 时长 | 说话人 | manifest SHA-256 |
|---|---:|---:|---:|---|

| dev | 14,326 | 18.089 h | 40 | `ca4c2f5b…cf9996a6` |
| test | 7,176 | 10.030 h | 20 | `ab36e937…1e86f887` |

官方 train/dev/test 的说话人集合互斥。派生清单固定随机种子 `2026`：20 小时训练子集为 15,943

`test_measured_rir` 为其 500 条嵌套子集。完整哈希、排除项、性别分布和切分统计均在审计 JSON。

## 3. 已冻结的模型和声学 smoke

- ASR：`openai/whisper-small`，revision `973afd24965f72e36ca33b3055d56a652f456b4d`；推理固定
  `language=zh`、`task=transcribe`、不输出 timestamps。
- RIR：四通道 5 cm 半径 UCA，Pyroomacoustics 控制房间几何；smoke 覆盖目标 RT60=`0.2/0.6/1.0 s`。
- 前端：Raw、S-WPE-10、S-WPE-40、M-WPE-10；WPE 不读取真值 RIR 或干净语音。
- 指标：中文规范化 CER 与 S/D/I；成对 bootstrap 是正式大样本阶段的置信区间方法。

## 5. 复现命令

```bash
python3 -m venv .venv-robust-asr
./.venv-robust-asr/bin/pip install -e '.[robust-asr,dev]'

export ROBUST_ASR_DATA_ROOT=/path/to/robust_asr
./.venv-robust-asr/bin/python scripts/robust_asr/prepare_aishell.py
./.venv-robust-asr/bin/python scripts/robust_asr/generate_rir_bank.py --help
./.venv-robust-asr/bin/python scripts/robust_asr/run_frozen_whisper_baseline.py \
  --device cpu --local-files-only
```

正式训练服务器上再安装训练依赖，并显式进入 CUDA：

```bash
./.venv-robust-asr/bin/pip install -e '.[robust-asr,robust-asr-train,dev]'
```

不在本机执行 LoRA 训练；当前 macOS 环境没有可用 CUDA，且用户已指定后续使用 Linux RTX 4070。

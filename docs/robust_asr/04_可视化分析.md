# 普通话混响鲁棒 ASR：可视化分析

最后更新：2026-08-29

本文把正式封存 test 的定性样本和统计结果可视化。图只用于解释已完成实验，
不参与 WPE 参数、LoRA 位置或 checkpoint 选择。

## 1. 受控样本时频图

样本固定为：

- utterance：`BAC009S0913W0222`；
- 文本：“央企在境外投资面临的问题很多”；
- clean 时长：3.88 s；
- RIR family：`test_r000_f000`；
- 声源—阵列距离：1.95 m；
- 同一房间和几何，只改变目标 RT60 与对应吸收率。

三列分别是 RMS 匹配的 clean、四通道参考通道 Raw 和 M-WPE-10 输出；三行是
RT60 0.2/0.6/1.0 s。所有子图使用 `jet` colormap 和同一 STFT dB 色标：
色标固定为 `[-100, -25] dB`，且没有对 Raw 和 WPE 分别归一化，因此子图之间的
能量强度可直接对比。白色虚线表示 clean 声源结束时刻，其右侧的能量是传播尾音。

![Clean、Raw 混响与 M-WPE 样本时频图](../figures/robust_asr_sample_spectrograms.png)

可直接观察到：

1. RT60 从 0.2 s 增至 1.0 s 时，Raw 中的音节边界和频谱间隙逐渐被横向拖尾填充；
2. 源语音结束后，0.6 s 和 1.0 s Raw 仍有明显低频及宽带残留能量；
3. M-WPE 保留了主要谐波与语音结构，同时缩短横向拖尾，重新显现部分音节间隙；
4. WPE 并未将输入完全恢复成 clean，在 1.0 s 时仍能看到残余低频能量与谱模糊。

这是一个受控定性样例，用于解释机制；是否改善 ASR 仍以 1,000 条 Whisper test 和
500 条 Paraformer test 的 corpus CER 与配对区间为准。

## 2. 300–1200 Hz 带通时域包络

为了更直观地查看混响拖尾，下图对同一组音频使用四阶 Butterworth
300–1200 Hz 带通滤波，经零相位滤波后计算 Hilbert 包络，再用 20 ms 窗平滑。
所有曲线共用同一幅度参考，因此 Raw 与 WPE 的强度差异仍被保留。左列是整句，
右列是相对 clean 声源结束时刻的尾音局部放大，竖线的相对时间为 0 s。

![300–1200 Hz 带通时域包络与混响拖尾](../figures/robust_asr_band_envelopes.png)

图中可见：

1. RT60=0.2 s 时 Raw 拖尾较短，M-WPE 与 Raw 的差异也较小；
2. RT60=0.6 s 时 Raw 在声源结束后仍保留较强能量，M-WPE 的衰减更快；
3. RT60=1.0 s 时 Raw 明显拖尾到约 1.1 s，M-WPE 的残余能量更弱，且约在
   0.8 s 后逐步消失，但仍未恢复成 clean。

带通包络用于说明拖尾的持续时间和相对强度，它是定性证据，不代替 RIR 的
RT60/DRR 声学测量，也不代替 ASR 的 CER 评测。

## 3. RIR 持续时间与强度

下图使用同一 RIR family 的参考通道。左图是 5 ms 平滑能量包络，三条曲线共用
幅度参考；右图是 Schroeder energy decay curve，圆点标记测得 RT60 的 `-60 dB`
位置。

![同几何不同 RT60 的 RIR 包络与能量衰减](../figures/robust_asr_rir_decay.png)

| 目标 RT60 | 测得 RT60 | 参考通道 DRR |
|---:|---:|---:|
| 0.2 s | 0.17 s | -5.4 dB |
| 0.6 s | 0.63 s | -9.4 dB |
| 1.0 s | 1.09 s | -11.3 dB |

它把时频图的现象与声学量联系起来：RT60 增大时，能量衰减更慢、尾音更长；
DRR 同时下降，表示反射能量相对直达声更强。

## 4. 正式统计效应对比

森林图统一展示 Robust（RT60 0.4–1.0 s）的绝对 CER 差值及 95% paired bootstrap
区间。负值表示改善，区间跨过零线表示当前实验不能证明额外收益。

![WPE 和 MCT 的 Robust CER 效应量与配对区间](../figures/robust_asr_effect_intervals.png)

该图将项目的核心结论压缩到同一坐标系：

- M-WPE 在 W0、Clean-LoRA、MCT-LoRA 和 Paraformer 上的 Robust 收益区间均低于零；
- MCT 相对 Clean-LoRA 在 Raw 上改善 `1.16 pp`，区间低于零；
- 加入 M-WPE 后，MCT 只改善 `0.10 pp`，区间跨零，表明二者对混响的收益高度重叠。

## 5. DRR 与同 RT60 内的 CER 退化

每个点代表一个 test RIR，y 轴是该 RIR 上各语句相对配对 clean 的平均 CER 退化。
线性导引使用对离群点稳健的 Theil-Sen 估计，统计量仍是预先确定的 Spearman ρ。
RT60=0.8 s 的 `108.4 pp` 离群点未删除，用三角形在图边界标注，避免压缩其余
RIR 的主体分布。

![同 RT60 内 DRR 与 W0 CER 退化的关系](../figures/robust_asr_drr_cer_relationship.png)

中重度三档的 Spearman ρ 为 `-0.406/-0.419/-0.455`，说明在 RT60 已固定时，
DRR 越低、直达声相对越弱，平均 CER 退化通常越大。散点仍有明显离散，所以 DRR 是
解释变量，不是完整决定识别难度的单一指标。

```bash
python scripts/robust_asr/plot_reverberation_examples.py \
  --data-root "$ROBUST_ASR_DATA_ROOT" \
  --spectrogram-output docs/figures/robust_asr_sample_spectrograms.png \
  --band-envelope-output docs/figures/robust_asr_band_envelopes.png \
  --rir-output docs/figures/robust_asr_rir_decay.png

  --whisper-interaction \
    "$ROBUST_ASR_DATA_ROOT/outputs/lora_wpe_interaction_test_1000utt_v1.json" \
  --paraformer-results \
    "$ROBUST_ASR_DATA_ROOT/outputs/frozen_paraformer_test_reverb_test_500utt_raw_mwpe_v1.jsonl" \
  --output docs/figures/robust_asr_effect_intervals.png

python scripts/robust_asr/plot_drr_cer_relationship.py \
  --results \
    "$ROBUST_ASR_DATA_ROOT/outputs/w0_whisper_test_reverb_test_1000utt_raw_mwpe_v1.jsonl" \
  --output docs/figures/robust_asr_drr_cer_relationship.png
```

所有图均是 PNG，输入样本、RIR family、RT60 和统计随机种子均固定。
